# ISO Collection 💿

A personal collection of operating-system ISOs, installers, beta builds, and other historical OS images for **testing, preservation, research, and virtual machines**.

> ⚠️ **Note:** This repository is primarily an index/collection. Make sure you have the legal right to download, use, or redistribute any copyrighted software included or referenced here.

## 🖥️ What You'll Find

This collection is intended for things such as:

- 🪟 Windows releases, editions, and beta builds
- 🐧 Linux distributions and older releases
- 🍎 macOS / OS X releases where legally redistributable
- 🧪 Experimental and pre-release operating systems
- 💾 Historical installers and recovery media
- 🔧 Images useful for VM testing and OS research

## 📁 Organization

ISOs should be organized by operating system and release where practical. Useful metadata may include:

- **OS / Product**
- **Version or build number**
- **Architecture** (x86, x64, ARM, etc.)
- **Edition**
- **Release date**
- **Language**
- **Source**
- **Checksums**, when available

## 🧪 VM Testing

These images are especially useful for experimenting with operating systems in virtual machines such as:

- VirtualBox
- QEMU
- Hyper-V
- VMware

For old or unstable builds, use a disposable VM and avoid connecting experimental systems to sensitive networks or accounts.

## 🔎 Sources & Preservation

Whenever possible, record where an image came from and preserve its original filename and build information. Historical builds can disappear from the modern internet, so accurate metadata is important for future research.

Recommended sources include official archives, vendor-provided downloads, and reputable software-preservation projects.
